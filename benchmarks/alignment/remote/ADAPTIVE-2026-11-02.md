# Native Linux/amd64 adaptive validation — 2026-11-02

All five validation checks passed on the Ryzen 5 7600X under Linux, using static
Go 1.27.2 binaries built from commit `8d57191`, `GOAMD64=v1`, and
`GOEXPERIMENT=simd` for the SIMD candidate. The selected backend was `avx2-16`.
Processes used `GOMAXPROCS=1`. Returned binary and input hashes match the bundle.

| Check | Result |
| --- | --- |
| Native AVX2 dispatch | Passed; `avx2-16` selected |
| Scalar alignment unit suite | Passed |
| AVX2 alignment unit suite and original-genome regressions | Passed |
| AVX2 disabled | Passed; scalar dispatch and adaptive boundary tests |
| Core AVX-512 features disabled | Passed; AVX2 dispatch and adaptive tests |

The AVX2 suite ran both full and adaptive modes against the original FASTA pair.
Both recovered the motivating missing region, replayed alignment operations
against DNA, and preserved exact input-swap symmetry. Both returned 7,116 paths;
equal counts do not imply identical full/adaptive paths.

The logged first comparisons took 6.842 s full and 3.871 s adaptive (1.77×).
These are single observations from correctness tests, not repeated performance
measurements. This run did not benchmark repeats or minimap2, or compare adaptive
whole-output hashes against the Mac. The scalar suite skipped the optional
original-genome tests; the SIMD suite ran them. Optional captured-workload tests
were skipped, and fuzz tests ran their seed corpus rather than a fuzz campaign.
All stderr logs were empty. Total check process time was approximately 26 s.

Raw check commands, timings, binary/input hashes, source fingerprint and success
status are in [adaptive-results-2026-11-02.json](adaptive-results-2026-11-02.json).
To reproduce using the existing bundle builder, copy the original FASTA pair
to the Linux host and run:

```sh
./run.sh --self-test-only --data /path/to/Seqhiker_debug
```
