# Native Linux/amd64 validation — 2026-10-23

Ryzen 5 7600X, Linux, Go 1.27.2, static `GOAMD64=v1` binaries; candidate built
with `GOEXPERIMENT=simd`. The selected backend was `avx2-16` (sixteen 8-bit
lanes). Full extension, indexed containment and the 20M benchmark anchor cap
were enabled in both scalar and SIMD builds. Each process used `GOMAXPROCS=1`.

## Results

Median whole-process wall seconds across three runs per backend and dataset:

| Dataset | Scalar | AVX2 | Speedup |
| --- | ---: | ---: | ---: |
| Original debug pair | 24.789 | 7.089 | 3.50× |
| Repeat-rich pair | 115.683 | 31.260 | 3.70× |

All twelve timed outputs exactly matched the previous reference PAF hashes:
7,116 paths for the debug pair and 42,414 for repeats. Both backends therefore
retain the validated full-extension output on these inputs. This end-to-end
speedup includes the shared difference-DP implementation and scratch reuse;
it does not isolate vector arithmetic from those implementation changes.

Scalar and AVX2 alignment unit tests passed. AVX2 tests included the original
missing-region/input-swap regression. Scalar fallback with AVX2 disabled passed;
AVX2 lane/kernel tests with core AVX-512 features disabled also passed.
The random/fuzz seed corpus ran as part of unit tests; this was not a timed
native fuzzing campaign.

Minimap2 was unavailable or explicitly skipped, so these results do not provide
a same-machine minimap2 comparison. Earlier ARM64 minimap2 measurements cannot
be directly compared with these Ryzen timings. No CPU profiles were requested.
The three repeats were collected sequentially by backend, without randomized
order; these are measurements of these inputs on this machine.

Raw process timings, CPU times, peak RSS, allocation totals, options, output
hashes and commands are in [native-results-2026-10-23.json](native-results-2026-10-23.json).
Returned binaries matched every SHA-256 hash in the locally built bundle.
